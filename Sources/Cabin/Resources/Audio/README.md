# Turntable audio

Drop a seamless **vinyl surface-noise loop** here named `vinyl-crackle`
(`.wav`, `.m4a`, `.mp3`, or `.caf`) and Cabin's turntable mode will loop it
instead of the built-in synthesized crackle. Use a clip you have the rights
to ship (CC0 / public-domain recommended). ~5–15 s, seamless, mono or stereo.
